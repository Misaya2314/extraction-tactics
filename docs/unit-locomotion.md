# 移动节奏与掩体过渡

在 Godot 中打开 `scenes/presentation/locomotion_showcase.tscn`，按 F6 运行。按 1 移至高掩体，按 2 返回低掩体。

实际战斗已通过 PrototypeController 接入：根据起点和终点的掩体边信息，先起身离开掩体，再移动、减速并进入目标掩体。途中刷新姿态不会覆盖移动动画。移动只改变表现，继续沿用原有 AP、路径合法性与占位结算。

- 默认最高速度 3.6 米/秒，加速度 14 米/秒²；直线路径点连续通过，转弯减速，严格沿原路径移动。
- 行走循环按距离采样，默认步幅 1.5 米。左右脚触地触发已有移动音效和少量短寿命扬尘；声音使用距离衰减。
- 移动单独使用 1.7 倍基础播放率，长路线行进最多 1.8 秒；路径曲线与距离驱动步态保持同步。编辑器中可调整 movement_playback_rate 与 movement_max_duration。
- 离开掩体过渡 0.12 秒；末段 0.8 米开始收姿，到达后用 0.12 秒完成低掩体蹲伏或高掩体侧身。正常帧率下，含两端掩体过渡的一次移动约不超过 2.04 秒（全局 1×）。
- 隐藏单位不发出脚步音效或扬尘；撤销或中断会取消移动并清理表现。

当前使用分段机器人姿态和距离驱动步态，尚未实现脚部 IK 或按地面材质切换脚步。扬尘与声音目前为统一原型资源。

实际关卡右上角任务栏左侧提供播放速度按钮，点击循环切换 1×、2×、4×，移动中也可切换。使用战斗场景时钟统一加快移动、动作、特效、镜头及敌方行动等待，不改变 AP 或伤害数值；音频保持原音调。离开场景恢复进入前的时钟倍率；速度选择保存到 `user://battle_speed.cfg`，新关卡沿用上次选择。

回归脚本：`tests/presentation/unit_locomotion_test.gd`，覆盖路径采样连续性、转弯减速、掩体过渡、左右脚交替、隐藏和取消。

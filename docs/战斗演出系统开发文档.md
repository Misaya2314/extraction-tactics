# 战斗演出系统（第一版）

## 已实现体验

- 单目标射击：越肩镜头；近距离优先侧面镜头；左右越肩和侧面候选均不可用时保留战术视角。
- 手雷与爆炸环境攻击：高位广角。同一行动内多个单位的伤害聚合展示，多个被摧毁的可见爆炸物同时播放扩散光球；普通物件破坏不生成爆炸光球。
- 命中反馈：沿受击方向偏移和倾倒、伤害数字、击杀提示、命中/死亡音效。霰弹枪的视觉位移强度大于步枪。
- 击杀慢动作：普通击杀基础概率 25%，普通高亮至少间隔两次行动；最后一击或多目标死亡优先。局部反应/爆炸前 0.3 秒实际时间以 0.3 倍速度播放，不修改 Engine.time_scale。
- 近景期间隐藏单位头顶状态和方向标记，结束恢复。镜头恢复到接管前的变换，镜头移动和滚轮缩放在接管期间禁用。
- 底部操作栏上方提供完整、仅击杀、关闭镜头演出三档，以及慢镜头开关；设置保存到 user://combat_presentation.cfg。关闭镜头后仍保留基础开火和受击反馈。
- 空格或 Esc 跳过当前演出。跳过仍完成视觉清理及结果展示，不重复结算伤害。

## 代码职责

- `scripts/presentation/combat_presentation_director.gd`：接管、行动前快照、行动后伤害聚合、镜头候选、局部演出时间、提示与清理。独立 RandomNumberGenerator 不消耗战斗随机序列。
- `scripts/core/combat/weapon_attack_feedback_profile.gd`：新增 impact_time（开火到命中的时间）和 impact_strength（纯视觉位移强度）。复用已有后坐力、枪口闪光及武器音效。
- `scripts/presentation/tactical_camera_rig.gd`：cinematic_active 期间暂停自由相机控制。
- `scripts/gameplay/prototype_unit.gd`：defer_damage_feedback 让伤害计算暂不立即播放声音，由演出控制器在命中点播放。
- `scripts/gameplay/environment/environment_object_view.gd`：保留被摧毁对象的视觉到命中点，碰撞仍立即按实际状态移除。
- `scripts/gameplay/prototype_controller.gd`：统一启动、等待演出，保留逻辑死亡单位的外观，演出结束后开放结果面板。技能入口改为调用已有 _execute_runtime_action，保证自伤、连锁伤害及行动点提交属于一次完整行动。

## 状态契约

1. 接管发生在执行器调用之前，保存存活单位 HP、位置、可见性、视觉姿态与音效延迟状态。
2. 执行器立即、仅一次结算伤害、AP、占位、回合名册和胜负；同时全灭仍优先判失败。
3. 根据快照和结算后 HP 生成每个可见受击单位的聚合记录。这里不复盘链式爆炸的逐次伤害顺序，不把演出当作第二次模拟。
4. 逻辑已死亡的单位不再参与战斗，外观暂留；失败行动立即释放接管。无伤害辅助技能直接结束接管，不播放射击镜头。
5. 死亡外观在演出结束后隐藏并禁用处理，视觉姿态复位供撤销使用。存活单位保持逻辑位置，不添加实际击退效果。
6. 结果可以在演出前成立，但结果面板必须等待演出结束；重开卸载旧演出，不能影响新场景。无场景测试调用同步清理，不等待不存在的帧。
7. 相机检查地面层 1 与掩体/墙体层 2，检查候选位置球形空间及到目标的射线。跨墙的镜头过渡使用切镜，不穿墙插值。未配置碰撞的装饰物仍需地编补齐碰撞才能参与检查。

## 当前美术范围

第一版使用项目现有模型的程序化倾倒，不含新的人形骨骼动画、布娃娃或角色专属处决。爆炸为程序化光球，沿用现有受击/死亡声音，尚未制作专用爆炸音效、碎片和手雷投掷动画。伤害与死亡在一次行动内聚合展示，连锁动画暂不逐桶错峰。

这些表现可在现有演出控制器上替换。应优先用正式模型调整取景距离、胸口瞄点与倒地动画，再增加更多镜头和动作素材。

## 验证

- `tests/presentation/combat_presentation_test.gd`：多目标死亡、隐藏目标不泄露、环境碰撞与外观分离、慢动作时间、跳过、相机精确恢复、撤销所需姿态复位、关闭/仅击杀模式、墙层遮挡退回及规则不变。
- `tests/session/mission_scene_test.gd`：真实主控制器的最终射击、胜负面板、演出中重开，以及从公开技能入口施放手雷造成双方同时死亡。
- 回归：攻击反馈、单位音效、环境集成、撤销、关卡目标、技能和探身射击测试。
- 使用 Godot 4.7 命令运行：`godot --headless --path . --log-file .godot/combat-test.log --script tests/presentation/combat_presentation_test.gd`。
- 去掉 headless 并添加 `-- --visual` 可保存测试近景到 `.godot/combat-preview.png`；`-- --main-preview` 可保存主场景界面检查图。

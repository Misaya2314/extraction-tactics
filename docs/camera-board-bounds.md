# 相机棋盘边界

战术相机的观察中心限制在实际可移动地格的水平投影附近，默认最多越出地格边缘约 1.5 格。限制按每块地格计算，所以地图声明范围内的大块空白、不规则边缘和孔洞也不会任意漫游。

以 GridModel 的 is_walkable 为依据，已被单位占用的可移动格仍计入边界；所有楼层合并投影。地图载入及环境规则重建时更新缓存，鼠标拖动、键盘移动、自动跟随及聚焦共同应用限制。空地图使用原点附近一格作为安全范围。

在 TacticalCameraRig 的 Inspector 调整 board_margin_cells，默认 1.5，设为 0 时观察中心不能离开地格边缘。非正方形地格使用较长边作为边距单位。

限制对象是观察中心，不是高处摄影机镜头的位置；缩放沿用原有 zoom_min/zoom_max。攻击与发现等演出机位保留原有镜头避障规则，自由观察模式尚未开发。

验证：tests/presentation/camera_board_bounds_test.gd 覆盖偏移棋盘、负坐标、不规则空洞、边距、聚焦及动态边界收缩。

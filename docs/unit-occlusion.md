# 角色遮挡处理

实际单位模型与武器现在附加遮挡剪影：对比场景深度和角色深度，仅显示被前景遮住的部分。阵营颜色沿用单位配色，选中单位更亮。镜头移动、角色动画和倍速自动沿用同一套表现，不修改掩体、射线或命中判定。

隐藏单位继承原有可见性，不会透出迷雾中的敌人。死亡后关闭剪影；更换武器重新绑定；退出场景清除实例覆盖材质。导入模型的共享材质不被修改。

在 Godot 打开 `scenes/presentation/occlusion_showcase.tscn`，按 F6：

- 1：切换遮挡墙。
- 2：隐藏或显示中间敌人，检查隐藏敌人不会出现剪影。
- 3：切换左侧友军的选中强调。

当前按不透明深度工作，玻璃等不写入深度的透明物体不触发效果。角色周围保留约 0.7–0.85 米的自身遮挡排除区，避免手臂和武器相互叠色；紧贴模型的遮挡可能不会强调。当前为柔和填色剪影，尚非独立屏幕描边。

验证：`tests/presentation/unit_occlusion_test.gd` 检查实例材质隔离、选中、隐藏、换武器与死亡；展示场景支持 `--occlusion-capture` 生成完全遮挡、隐藏敌人、部分遮挡和无遮挡截图。

## 建议的后续开发顺序

1. 战术预览：移动落点的掩体等级、预计 AP，以及从该位置可攻击的已知目标。优先复用实际战斗查询，减少预览与结算不一致。
2. 建筑可读性：屋顶与前景墙分组，跟随当前楼层隐藏屋顶或淡化墙面，同时保留掩体边界。剪影能找到角色，场景淡化能帮助判断周围地格。
3. 武器表现差异：为步枪、霰弹枪等分别调整射击节奏、后坐和声音，继续使用统一演出时间线与播放倍率。
